# Glossary

| Term | Meaning |
|---|---|
| ADR | Architecture Decision Record; a dated note explaining a decision and its consequences |
| Argon2 | Password hashing algorithm used by Auth |
| BFF | Backend for Frontend; an API layer tailored to the UI |
| Canvas | Obsidian's interactive visual document format |
| Compose | Docker Compose; defines the local multi-container stack |
| IDOR | Insecure Direct Object Reference; accessing another user's object by changing an ID |
| JWT | JSON Web Token; signed identity token used between services |
| JWKS | JSON Web Key Set; public-key discovery endpoint |
| MCP | Model Context Protocol; tool and data integration for agents |
| MOC | Map of Content; a note that links a topic area |
| P0 | Blocking or security-critical issue |
| P1 | Important issue that should be fixed before a release |
| P2 | Polish or maintainability issue |
| RS256 | RSA signature with SHA-256; the JWT algorithm used here |
| SDD | Subagent-Driven Development; a Superpowers workflow |
| Traefik | Edge reverse proxy and router |
| Vault | The Obsidian knowledge base at `docs/obsidian/` |
| YARA | Pattern-matching rules for malware analysis; not implemented yet |
